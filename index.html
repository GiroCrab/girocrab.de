GiroCrab

Natives, datensparsames Online-Banking für macOS

Download für macOS
  • Apple-notarisiert
  • 100 % lokal
  • Open Source (Rust + SwiftUI)
  • Direktes FinTS ohne Mittelsmann

Features

Datenschutz

Kein Tracking, keine Cloud. Händler-Logos und Favicons werden nur geladen, wenn du das aktivierst (Opt-in).

Performance

Der Kern ist in Rust geschrieben: schnell, speichersicher und mit verschlüsseltem lokalem Tresor.

Komfort

Schnelle Notizen zu Buchungen per Doppelklick oder Return und Import aus MoneyMoney.
