Alternativ: git clone https://github.com/GiroCrab/GiroCrab.git && cd GiroCrab && claude
🧠 Das Beste daran: Claude liest beim Start automatisch unsere CLAUDE.md im Hauptordner und weiß sofort, wie GiroCrab gebaut und getestet wird.

### 🦀 In 4 Schritten zum eigenen Pull Request mit KI – auch ohne Programmierkenntnisse!

Du hast einen Fehler gefunden oder wünschst dir eine Funktion in **GiroCrab**, programmierst aber selbst kein `Swift` oder `Rust`? **Kein Problem!**
Wenn du ein KI-Abo (z. B. **Claude Pro / Claude Code** oder **Cursor**) hast, kannst du deinen Wunsch in wenigen Minuten selbst einbauen. In unserem Repository liegt eine fertige `CLAUDE.md`-Datei, die deiner KI automatisch unsere gesamte Architektur, alle Regeln und die Selbsttests erklärt.

#### 1️⃣ GiroCrab öffnen & Claude Code starten
- **In der Claude Desktop App (Reiter „Code“) oder Cursor:** Klicke auf *Repository klonen* und gib `https://github.com/GiroCrab/GiroCrab.git` ein.
- **Oder im macOS Terminal:**
  ```zsh
  gh repo fork GiroCrab/GiroCrab --clone && cd GiroCrab && claude
  ```
  *(Claude liest beim Start automatisch unsere `CLAUDE.md`.)*

#### 2️⃣ Deinen Wunsch auf Deutsch eingeben
Kopiere einfach diesen Auftrag (mit deiner Issue-Nummer) in Claude Code:
```text
Bitte schau dir Issue #383 in GiroCrab/GiroCrab an. Suche die passende Stelle im Code, baue die Lösung gemäß CLAUDE.md ein, führe die Tests (swift test / cargo test) aus und starte die App danach im sicheren Demo-Modus (GIROCRAB_DEMO_SEED=1 swift run --package-path GiroCrabApp GiroCrabMac), damit ich es ausprobieren kann.
```

#### 3️⃣ Im sicheren Demo-Tresor anschauen
GiroCrab öffnet sich automatisch mit reinen **Beispieldaten** (`GIROCRAB_DEMO_SEED=1` – deine echten Kontodaten werden nicht berührt). Klicke deine neue Funktion an! Wenn du noch etwas ändern möchtest, schreib es Claude einfach auf Deutsch (z. B. *„Mach den Button noch etwas breiter“*).

#### 4️⃣ Pull Request mit 1 Satz absenden
Wenn im Demo-Modus alles passt, brauchst du keine Git-Befehle zu kennen – schreib einfach:
```text
Super, das funktioniert! Bitte erstelle jetzt einen neuen Branch, führe alle Prüfskripte laut CLAUDE.md aus, committe die Änderung und öffne einen Pull Request auf GitHub für Issue #383.
```
